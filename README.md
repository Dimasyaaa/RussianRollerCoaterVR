## Описание проекта

Проект разработан в рамках курса **"Разработка VR сред"**.

Приложение воссоздает реальные покатушки на «Американских горках», предлагая пользователю пройти полный цикл взаимодействия: от свободного исследования парка и покупки билета до захватывающей поездки по протяженному маршруту с ощущением скорости и атмосферы реальных горок.

## Реализованные функции

### Аттракцион и физика
- **Протяженный маршрут**: Замкнутая трасса длиной **>1000 метров**, построенная на базе `Path3D` и `PathFollow3D`.
- **Детализированные рельсы**: Два металлических рельса, деревянные шпалы и металлические трубчатые опоры (созданы встроенными средствами Godot).
- **Вагонетка**: Кастомная модель с сиденьем, **анимированными вращающимися колесами** и встроенным вторым `XROrigin3D` для бесшовного переключения камер.
- **Физика наклона**: Интерполяция вращения камеры на поворотах для эффекта реалистичного наклона вагонетки.

### Интерактивность и экономика
- **Билетная касса**: Подсветка лотка для денег при приближении/взгляде.
- **Механика оплаты**: Взаимодействие с кошельком (grab & drop). При помещении кошелька в лоток срабатывает звук монет и **анимация открытия ворот**.
- **Сценарий посадки**: Бесшовное переключение управления с игрока в парке на игрока в вагонетке, обратный отсчет и автоматический запуск движения.
- **Завершение поездки**: По окончании маршрута вагонетка останавливается, камера возвращается к основному игроку, который спавнится за пределами аттракциона.

### Окружение и атмосфера
- **Ландшафт**: Смешанная местность (равнины, холмы, горы), созданная с помощью плагина HTerrain.
- **Ограждения**: Забор по периметру парка с настроенными collision layers (блокирует проход игрока).
- **Анимированные декорации**: 
  - Мельница с вращающимися лопастями.
  - Аттракцион «Орбита».
  - Аттракцион «Лодка».
- **Динамическая среда**: Цикл смены дня и ночи с автоматическим включением гирлянд и освещения, а также система частиц `GPUParticles3D` для эффекта встречного ветра.

### Звуковое сопровождение
- Пространственный звук (3D Audio): скрип вагонетки, шум ветра, звуки парка и характерный звук падения денег при оплате.
